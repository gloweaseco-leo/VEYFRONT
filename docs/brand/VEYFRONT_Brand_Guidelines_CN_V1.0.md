# VEYFRONT 品牌视觉识别系统 V1.0

**状态**：品牌视觉定稿候选 / 待品牌方确认与法律检索。视觉母版已经完成，**不代表商标、域名或独占性已确认**。

## 1. 品牌定位

- Brand: **VEYFRONT**
- Brand meaning: **View · Empower · Yonder**（品牌理念，不是固定英文词源）
- Brand line: **Building Digital Frontiers for Global Business**
- Commercial descriptor: **AI-powered B2B websites for global business**
- 中文表达：**为全球商业，构建数字新前沿。**
- 新站与老站改造两条服务路径，保持分别清楚的入口。
- L2M 为内部技术引擎，对外以 VEYFRONT 作为统一品牌。

## 2. Logo 结构

**Open V**：深色或米白的 V 字主形 + 向右开放的亮绿短横。主形表达 View / VEYFRONT，短横代表 frontier / horizon。主字标以 Inter Display Bold 为基础转为矢量轮廓，避免字体缺失导致 Logo 走形。字标不添加发光、立体、阴影与渐变。正式商标使用前须进行冲突检索。

- 主组合横版：符号在左，VEYFRONT 右侧。
- 保护空间：四周至少等于图标宽度的 0.2 倍，正式商标核准后再形成测量图。
- 优先最小宽度：160px（网页）；图标最小 24px（需小尺寸实际可读性复测）。
- 反白版：深墨背景 / 米白 Logo / 亮绿短横。
- 浅色版：米白背景 / 深墨 Logo / 亮绿短横。
- 纯色版：全黑或全白，适合印刷和不能使用品牌强调色的场景。
- 禁止：挤压、旋转、单独改 V 的角度、把品牌绿色涂满字标、加阴影或光晕。

## 3. 色板

| Token | 色值 | 用途 |
|---|---|---|
| `brand.ink` | `#17262D` | 页眉、标题、深底章节、主要品牌字 |
| `brand.ivory` | `#F7F7F2` | 正文背景、深底反白字 |
| `brand.lime` | `#B8F06B` | 主 CTA、焦点提示、品牌标志短横 |
| `brand.mist` | `#D9E5E4` | 次级分区、信息内容容器 |
| `brand.slate` | `#60737A` | 辅助文字；具体字号/背景须对比度校核 |

- 避免 Electric Lime 在 Warm Ivory 上直接显示小字。
- WCAG 2.2 AA：普通文字对比度目标至少 4.5:1；大型文字至少 3:1；非文字交互图形按实际场景测试。
- 核心网站作品保留客户自身颜色与图形，VEYFRONT 只管理画框、注释和交互。

## 4. 字体与版式

- 英文标题：Inter Display 或 Geist，同级现代无衬线。字标轮廓已内嵌 SVG，无需额外字体。
- 英文正文：Inter / Geist，正文 16–18px，行高 1.5–1.7。
- 中文：Noto Sans SC（或思源黑体）正文及标题。
- 数据标签：Geist Mono 或常规等宽字体，少量使用。
- 桌面 H1 建议 56–72px；手机 H1 建议 34–40px；按语言、文本实际折行调节。
- 页面内容最大宽度建议 1280–1360px；桌面12列 / 手机4列；8px 间距基线。

## 5. 品牌图形

- **Frontier Line**：精确的向右行进曲线/线段，不做地球地图装饰。
- **Open Frame**：在完整矩形框上保留开放断口，表达数字商业入口。
- **Evidence Grid**：构建证据、有来源的截图、前后对比。
- 不允许用抽象图形替代真实作品，尤其不能把不同企业网站拼接为真实 Before/After。

## 6. 官网落地与增长

- Hero 同时解释新网站建设和旧网站重建，链接两个各自有效的转化入口。
- 旧站入口继续保留 URL → 诊断/方案的核心路径；新站入口根据实际交付能力接入项目启动/需求收集，不虚构自助生成。
- 主按钮高亮不等于必须每个按钮全绿；采用等级明确的 CTA 系统。
- 关于能力、客户案例、交付时间、SEO、询盘增长的声明必须可举证。
- 1440/768/390/360px 多断点与英文/中文均需验收。
- 动效主要用于状态切换，支持 reduced motion。

## 7. 开发接入

关键文件建议：`components/l2m/brand.tsx`、`app/globals.css`、`app/layout.tsx`、`components/home/hero.tsx`。先建立 design tokens 与 Logo 组件，再改页面；避免让 Logo 设计触发 L2M 引擎范围变更。当前仓库中较完整的八屏官网原型在 `chatgpters6/L2M-Web2`，原始 `gloweaseco-leo/L2M-Web` 为历史设计分支。

## 8. 发版前门禁

1. 品牌负责人确认标志结构、字体和主色。
2. 法律专业人员检索 VEYFRONT / 相似标识在目标地区相关类别的商标冲突。
3. 验证 Logo 在深浅背景、24px 图标、移动端页眉、黑白打印中的可辨性。
4. 网站表述与实际可交付能力一致；占位作品、诊断、价格均显式标记 Demo。
5. 实际浏览器与可访问性审核通过后才能正式上线。
