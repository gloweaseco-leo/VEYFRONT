# VEYFRONT 外贸独立站免费预诊断 V1

## 基线与页面决策

审计基线为 `main@348ba4a6a9e885431e769e008dd4b7c157405104`。首页保留 Launch 和 Rebuild 两条路径，Rebuild 原咨询通过 `/api/leads` 私有保存，成功回执以入库为准。线上中文使用无前缀路径，英文使用 `/en`。Vercel 项目启用了预览保护，线索存储凭据同时覆盖正式和预览环境。

| 位置 | VF-A 行为 |
| --- | --- |
| 首页首屏 | 在「已有旧网站」附近增加次级预诊断入口，原接洽入口继续可用。 |
| Rebuild 咨询 | 侧栏增加预诊断入口。由专业诊断按钮进入时，预填一段可编辑的咨询说明。 |
| `/website-diagnosis` 与 `/en/website-diagnosis` | 公开网址格式检查、授权说明、虚构任务演示、可展开证据、Rebuild 和微信衔接。预览内切换语言保留当页状态。 |
| Launch、Rebuild、Contact 与隐私请求 | 预览可试填并检查字段。预览 API 在读取请求体前拒绝写入。需要真实联系时，表单内链接跳转至正式官网相应页面。 |
| SEO 与数据 | 仅预览环境展示入口。诊断页标记 noindex、no-referrer，排除在 sitemap 外。诊断预览页的 Analytics 与 Speed Insights 事件过滤掉，原有正式站配置保持。 |

### 客户实际得到什么

1. 输入公开网址，阅读范围和授权说明，看到本地格式检查结果。有效地址仍显示自动诊断尚未开放，页面不会把填写的内容发送给服务器、访问该网站或创建任务。
2. 单独打开虚构工业阀门示例，可以从申请、排队、执行走到报告，也可切换局部缺失、失败、过期、暂不可用及授权失效。步骤由预览操作者手动推进。只有演示的完成或部分完成状态显示报告。
3. 报告先呈现覆盖范围、已确认事项和有原文支撑的优先建议，再按五类采购任务展开。证据含页面地址、位置与摘录，使用结构化文本呈现。把事实、买家可能受到的影响、建议分开。没有依据的部分用 UNKNOWN，未提供分享入口。
4. 看过价值后可选择咨询 Rebuild、查看企业微信二维码或提交专业诊断需求。输入框里的地址与虚构报告均不自动传入咨询，试填不产生线索、回执或通知。

## VF-B 最小接口草案

这些为对接要求。路径名称由 VEYFRONT 和 VRAE 接口负责人定稿。

| 接口或动作 | 最小请求与响应 |
| --- | --- |
| 创建任务 | VF 服务端向固定 VRAE 服务身份提交规范化目标、语言、适用的授权引用、同意版本、接受时间和幂等键。按申请主体与授权范围绑定幂等性。返回不透明任务引用、初态和可选重试间隔。只有 VRAE 确认接受后才显示「已接受」。 |
| 查询任务 | 服务端按任务引用和访问主体读取。返回已接受、执行中、完成、部分完成、失败、过期、暂不可用或访问结束等状态，含可展示的原因代码和更新时间。允许时返回已发布报告版本；客户端停止轮询终态，服务暂不可用时保留咨询退路。 |
| 返回查看、读取报告 | 独立签发、验证并撤销访问授权。任务引用仅用于定位。优先采用受控返回凭证交换 HttpOnly 同站会话，免登录保存期内可恢复。每次读任务、报告版本和证据均校验主体、授权、到期及撤销；无权限时采用统一反馈，不泄露任务是否存在。 |
| 客户侧报告 | 返回允许发布的最小投影及版本，包含目标、检查时间、来源、尝试和成功覆盖页、五类采购任务、确认项、VRAE 排序的最多三项有证据的优先内容。每项包含判定、观察事实、可展示来源位置与摘录、UNKNOWN 原因及待核对步骤。把商业假设和建议单独标注，VF 不补判、不补分。 |
| 可选关联原线索 | 只有客户主动提交咨询且服务端再次验证诊断访问授权后，才将受控的内部引用关联到私有线索。独立保留咨询同意与诊断同意，报告点击和任务完成均不创建线索。联系、商机及报价继续以既有业务流程为准。 |

VF 服务端以受控网关身份对接 VRAE。VF 不从浏览器或服务端向客户输入的网址发起探测。VRAE 验证允许访问的范围并执行隔离访问策略、跳转约束和资源限额。网站访问授权与声明独立，报告公开分享也需要独立批准。报告读取及授权恢复使用私有、不可公用缓存的响应；目标网址、证据、报告正文、联系方式和授权凭证不出现在浏览器地址栏、公共分析或通用日志。到期、撤销、响应校验不通过或 VRAE 断线时，关闭相应诊断能力并保留咨询。访问控制、安全缓存和限额由真实接口验收；本轮浏览器验证仅覆盖 VF-A 的无网络路径与预览边界。

## 验收与回滚

- Vercel 独立预览可操作。中英文覆盖 320、375、390 和 1440 像素，检查格式错误、授权未勾选、长网址和长证据、全状态、证据定位、语言切换、无真实提交及正式咨询跳转。
- 回归现有首页、价格、交付流程、案例、Launch、Rebuild、联系、企业微信、隐私、SEO 和移动端导航。无真实线索写入测试。CI 复用既有 Chrome 步骤及证据目录下的 VF-A 子目录。
- 预览阶段可停止使用该分支预览或关闭草稿 PR。正式环境门禁不展示 VF-A；没有诊断任务数据、迁移、秘密变量或新基础设施需要清理。若将来批准合并，按相关提交独立回退，不动线索库。
- Owner 本轮验收入口、文案、报告表达与正式咨询分流。进入 VF-B 前另外确认首批开放对象、接受的目标授权方式、返回凭证签发、报告审核/撤销机制、保存期限以及生产开关。待真实服务验收后再调整诊断隐私说明与保留承诺。
